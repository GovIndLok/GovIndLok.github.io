AI Knowledge Agent for Obsidian Vaults GitHub ↗

Autonomous agentic pipeline that packages raw documentation and Obsidian markdown notes into structured Open Knowledge Format (OKF) bundles for consumption by downstream AI agents.

  • Engineered with Google ADK 2.0 and Gemini API to orchestrate multi-step autonomous knowledge structuring.
  • Implemented human-in-the-loop review-and-approval gates to control which notes and knowledge boundaries agents can access.
  • Built an automated evaluation harness with programmatic unit checks and LLM-as-a-judge scoring (Gemini Flash Lite) for verified output quality.

F1 Racing Analytics Platform & MCP Server GitHub ↗

HTTP-based Model Context Protocol (MCP) server integrated with an AWS lakehouse, letting AI agents autonomously discover and execute SQL queries across 70+ years of Formula 1 telemetry.

  • Architected with FastMCP, enabling LLMs to inspect telemetry schemas and generate valid analytics queries autonomously.
  • Built an AWS lakehouse with S3, AWS Glue, Athena, and dbt integrating historical race data and the FastF1 API.
  • Reconciled driver and constructor histories with SCD Type 2 snapshots for deterministic historical versioning.
  • Automated post-race delta ingestion and state caching via AWS Lambda, EventBridge, and DynamoDB.
