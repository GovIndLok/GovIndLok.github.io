# Govind Lokam — Portfolio (Hybrid Editorial v1)

A static portfolio built with plain HTML, CSS and a small amount of vanilla JavaScript.

## Files

- `index.html` — homepage and selected work
- `projects.html` — project details
- `experience.html` — professional experience
- `skills.html` — technical skills
- `contact.html` — contact and social links
- `style.css` — visual system, responsive layout and reduced-motion support
- `script.js` — theme toggle and active navigation state

## Notes

- The theme preference is saved in browser `localStorage`; if storage is unavailable, the site still uses the system colour preference.
- The project cards currently use typographic presentation rather than screenshots because project image assets were not part of the supplied source files. Add real screenshots later if you want image-led project cards.
- A server-backed contact form, database or Python service cannot run on GitHub Pages itself. Use external services only if that functionality becomes necessary.
- Check all content, project links, and the layout on desktop and mobile before publishing.
